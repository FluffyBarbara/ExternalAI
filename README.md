<h1 align="center">ExternalAI</h1>

<p align="center">Голосовой ассистент в духе J.A.R.V.I.S. Понимает русскую речь, управляет компьютером и с помощью ИИ выполняет почти любую просьбу.</p>

---

## Возможности

- **Голос офлайн.** Распознавание русской речи работает без интернета (Vosk). Модель (~45 МБ) скачивается при первом запуске.
- **Ключевое слово.** Скажите «Джарвис, открой ютуб» — одной фразой или с паузой после имени. Слово можно сменить в настройках.
- **Ответы голосом.** Используется синтезатор речи системы, голос, скорость и тон настраиваются.
- **Более 100 встроенных команд.** Они работают мгновенно и без ИИ:
  - программы, сайты, папки и файлы (найти, открыть, создать), корзина, разделы настроек Windows;
  - поиск в Google, YouTube, Яндексе, магазинах и на картах;
  - громкость, музыка, яркость экрана;
  - горячие клавиши и вкладки: «новая вкладка», «обнови страницу», «прокрути вниз», «нажми контрол шифт т»;
  - управление окнами;
  - таймеры, будильники, напоминания, секундомер, заметки;
  - погода, курсы валют ЦБ, время в других городах, сколько дней до праздника;
  - калькулятор, пароли, IP, проверка интернета, чтение буфера и выделенного текста;
  - диски, батарея, скриншоты, выключение и блокировка ПК.
- **Понимает с полуслова.** «Можешь открыть ютуб?», «ютуб открой», просто «ютуб», «звук побольше», «трек другой» — всё это сработает. После команды можно уточнить: «ещё», «ещё тише», «а в Питере?».
- **Учится сам.**
  - Всё, что сделал ИИ, запоминается, и в следующий раз та же просьба выполняется мгновенно и без ИИ.
  - Свои команды голосом: «когда я говорю „рабочий режим“, открой телеграм, открой почту и громкость 30».
  - Если ассистент ошибся, скажите «не то», а затем что нужно было сделать — он запомнит.
  - ИИ запоминает факты о вас («запомни обо мне: я дизайнер»). Всё выученное видно и редактируется в **Настройки → Обучение**.
- **ИИ Claude для всего остального.** Создать папку, найти файл, узнать новости, поменять настройки, написать письмо — ассистент сам выполнит команды на компьютере. Опасные действия он делает только после подтверждения: голосом («да» / «нет») или кнопкой.
- **Красивый интерфейс.** Анимированное «ядро», которое реагирует на голос, панели системы, погоды, таймеров и заметок, журнал диалога.
- **Работа в фоне.** Сворачивается в трей и продолжает слушать. Глобальная горячая клавиша `Ctrl+Shift+Space`, есть автозапуск с системой.
- **Больше 27 000 команд в каталоге.** Основную часть дают конвертации между ~160 валютами в любую сторону (≈25 000). Остальное — 1 600 пересчётов единиц измерения, время в 418 часовых поясах, ~250 сайтов с поиском, перевод на 100+ языков, праздники, математика, работа с выделенным текстом. Точный счётчик с разбивкой — в справке (`F1`).
- **Лёгкие обновления.** Скачиваются только изменённые файлы — обычно десятки килобайт, а не установщик. Обновление ставится сразу, приложение само перезапускается и показывает «Что нового». Если новая версия не запустится, ExternalAI вернётся к предыдущей. Полный пакет нужен, только когда меняется Electron или библиотеки, и тогда он тоже ставится сам и тихо.

## Установка

1. Откройте [Releases](https://github.com/FluffyBarbara/ExternalAI/releases/latest).
2. Скачайте файл для своей системы:
   - **Windows:** `ExternalAI-Setup-x.y.z.exe`
   - **Linux:** `ExternalAI-x.y.z-x86_64.AppImage` или `.deb`
   - **macOS:** `ExternalAI-x.y.z-arm64.dmg` (сборка не подписана: при первом запуске нажмите «Открыть» в контекстном меню)
3. Запустите установщик. При первом запуске ExternalAI скачает модель речи.

> Windows SmartScreen может предупредить о неизвестном издателе, потому что установщик не подписан сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае».

## Подключение ИИ (рекомендуется)

1. Получите API-ключ на [platform.claude.com](https://platform.claude.com/settings/keys).
2. В ExternalAI: **Настройки → Искусственный интеллект** → вставьте ключ → «Проверить».
3. Выберите модель. По умолчанию стоит Claude Opus 5.5, для более быстрых ответов подойдёт Sonnet 5.5 или Haiku 5.5.

Ключ хранится только на вашем компьютере (в папке данных приложения). Если Claude недоступен в вашем регионе, укажите адрес прокси в поле «Адрес API».

Пока ИИ не подключён, работают все встроенные команды, а непонятные запросы ассистент ищет в Google.

| «Разбуди меня в 7 30» | будильник |
| «Запомни, что ключи в куртке» / «прочитай заметки» | заметки |

| «Сколько будет 25 умножить на 4» | калькулятор |

| «Выключи компьютер через 30 минут» | выключение после подтверждения |

Полный список — кнопка «?» в приложении или `F1`.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+Shift+Space` (глобально) | показать окно и слушать команду |
| `Esc` | остановить речь / закрыть окно |
| `F1` | список команд |
| `Ctrl+,` | настройки |
| `Ctrl+L` | перейти к текстовому вводу |

## Если что-то не работает

- **Плохо распознаётся «Джарвис».** Офлайн-модель знает не все редкие слова. Добавьте своё ключевое слово (например, «компьютер») в **Настройки → Голос**.
- **Нет русского голоса.** Windows: Параметры → Время и язык → Речь → Добавить голоса → Русский. Затем выберите голос в настройках ExternalAI.
- **Модель речи не скачивается.** Скачайте вручную [vosk-model-small-ru-0.22.zip](https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip) и выберите файл кнопкой «Выбрать файл модели…».
- **Ассистент слышит сам себя.** Используйте наушники или уменьшите громкость колонок. Пока ассистент говорит, он реагирует только на «стоп» и ключевое слово.

### Структура

```
src/
  main/         главный процесс Electron
    main.js       окно, трей, горячая клавиша, протокол app://, IPC
    actions.js    системные действия (программы, звук, питание, скриншоты, shell)
    ai.js         Claude с инструментами для управления компьютером
    model.js      загрузка и подготовка модели Vosk
    updater.js    автообновление из GitHub Releases
    store.js      настройки
    preload.js    безопасный мост к интерфейсу
  renderer/     интерфейс (HTML/CSS/JS)
    js/app.js       логика интерфейса, ключевое слово, таймеры, виджеты
    js/commands.js  встроенные русские команды
    js/speech.js    распознавание (Vosk), синтез речи, звуки
    js/reactor.js   анимация «ядра» и фона
  shared/text.js  нормализация текста и русские числительные
```

### Как выпустить новую версию

Установленные копии ExternalAI проверяют обновления при запуске и каждые 2 часа. В релиз workflow кладёт `update-manifest.json` со списком файлов кода и их хешами. Приложение скачивает только изменённые файлы с GitHub, проверяет хеши, ставит обновление и перезапускается. Если поменялись Electron или зависимости, ставится полный пакет через electron-updater.

Что писать в «Что нового»: добавьте раздел `## x.y.z` в `CHANGELOG.md` до выпуска. Если раздела нет, туда попадут заголовки коммитов.

Чтобы выпустить версию:

1. На GitHub откройте **Actions → «Релиз» → Run workflow** и введите номер версии, например `1.0.1`.
2. Workflow поднимет версию в `package.json`, создаст тег, соберёт установщики для Windows, Linux и macOS и опубликует релиз.

Можно и из терминала:

```bash
git tag v1.0.1
```

```bash
git push origin v1.0.1
```

Автообновление работает в установщике Windows (NSIS), AppImage и macOS-сборке (на macOS обновления требуют подписи приложения).
